# PR Summary: Legacy vs. Refactored Behavior Comparison

Below is a detailed comparison of the codebase before and after the implemented refactoring. You can copy and paste this table directly into your Pull Request description.

| Component / Feature | Legacy Behavior (Before) | Refactored Behavior (After) | Rationale & Benefits |
| :--- | :--- | :--- | :--- |
| **RLM Primitives Retrieval** | Two separate tools: `list_primitives()` and `lookup_primitive(key)` were called sequentially by the agent. | Consolidated into a single [`get_primitives()`](file:///Users/ssweeti/Desktop/GAH_v2/tools/primitive_lookup.py) tool. | **Performance & Cost**: Reduces network roundtrips, planning steps, and model latency. |
| **Primitives Backend APIs** | Endpoints `/internal/list-primitives` and `/internal/lookup-primitive` returned raw schemas including templates and validation scripts. | Single `/internal/get-primitives` endpoint maps to [`get_primitives_for_agent()`](file:///Users/ssweeti/Desktop/GAH_v2/backend/primitives_read/store.py), which strips `template` and `verification` fields. | **Context Windows**: Prevents the RLM context from bloating with large Python/CadQuery code templates, saving tokens. |
| **Verifier Parameters** | `verify_geometry(prompt, code, metrics, render_png)` accepted the generated Python code block. | `verify_geometry(prompt, metrics, render_png)` has the `code` parameter removed. | **Model Inputs**: Avoids code-bloat. Visual rendering (PNG) + CAD kernel metrics (volume/bbox) are sufficient to judge accuracy. |
| **Verifier Failure Classification** | No structured error tags; only returned a basic `passed: bool` and a descriptive message. | Returns `passed`, `feedback`, and a structured `failure_category` (e.g. `verifier_miss`, `visual_mismatch`, `geometry_invalidity`). | **Observability**: Automatically tags failures using standard repo-wide categories for automated pipelines. |
| **Run Artifact Storage** | Renders and trace logs saved scattered in `/outputs/` and temp paths. | All runs generate consistent outputs stored in `/artifacts/` at the repository root. | **Traceability**: Consolidates all execution artifacts, STL meshes, views, and JSON traces in a single place. |
| **Default Gemini Models** | Configured to fallback on `gemini-3.1-pro-preview`. | Swapped default judge and RLM config to `gemini-3.5-flash`. | **Rate Limits & Speed**: Circumvents 0 request/min quota exhaustion errors on Gemini Pro free tier accounts, ensuring continuous execution. |
| **Reasoning Skills Guides** | `repair_guidance.md` and `refinement_guidance.md` instructions recommended editing raw python code strings. | Instructions modified to guide the agent in fixing properties in the `PrimitivePlan` JSON representation. | **Correctness**: Eliminates syntax errors by keeping planning semantic and structured. |
| **Test Verification** | Separate tests for legacy endpoints; basic test runs. | Updated [`tests/test_backend_bridge.py`](file:///Users/ssweeti/Desktop/GAH_v2/tests/test_backend_bridge.py) and restructured [`Task_test_complex.py`](file:///Users/ssweeti/Desktop/GAH_v2/Task_test_complex.py) to run sequential bracket/plate tests. | **Reliability**: Guarantees zero regression on consolidated routes and parameters. |
